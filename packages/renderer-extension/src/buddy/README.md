# Buddy 控件

`installBuddyControl` 从现有 renderer 绑定获取当前 Codex 任务、输入框锚点和 Host 客户端，在输入框前放置 Auto Router。仅通过共享浏览器安全契约调用 Host；不读取 Node、文件或供应商凭据。

提供双语、键盘可操作的开关、角色和两档模型设置。面板采用双栏紧凑布局，帮助说明放在控件提示中；普通路由关闭或隐私开关开启时隐藏无意义的普通路由下拉框。刷新和中断会话入口共用底部操作行。展示规则评分、阶段、任务包、原生接受的模型和旁路退出码。状态每 1.2 秒读取一次，只有手动刷新或真实路由访问模型目录。`dispose()` 释放轮询和 DOM。

“JEV 判断”开关控制 System One 回合判断，开关下方提供密码类型 API Key 输入、保存与清除，仅显示“已配置/未配置”；详情行显示 JEV 模型和逐题状态。推送模型旁路以蓝色“旁路 · 垃”突出显示，折叠时仍展示实际模型、跳过夯规划和旁路回合成功率。详情显示样本数、统计口径及附带技能；完成、失败和取消后保留旁路标识，不与零模型命令旁路混淆。

模型收藏由 `renderer-model-shortcuts.ts` 管理，复用 `renderer-model-favorites.ts` 的 Harness 隔离存储。原生绑定只读取已发布的菜单属性并调用同一选择回调。点击 chip 通过 `renderer-fixed-model-selection.ts` 先停用自动规划和隐私改写，成功后才切换模型；关闭自动策略保留规划偏好，面板可再次开启。

折叠摘要和“本次任务模型”展示规划模型、执行模型、任务中切换过的模型及已报告的子代理模型，去重并允许换行，不把整个候选目录列作参与模型。兼容旧 Host 未提供模型记录时的当前规划/执行字段。显式指定执行模型时，提示单模型执行、禁止子代理和自动换模；选择“动态选择”恢复自动策略。

通过 `node tools/buddy/preview.mjs` 验证真实组件的模拟场景；执行 `npm run build:renderer` 后由主 renderer 扩展安装。夹具不能替代完整桌面绑定验收。参见 [功能说明](../../../../docs/product/buddy-auto-router.md)。

隐私模式不挂载独立输入区，也不隐藏原生 composer。启用隐私开关后，隐藏手动选模和普通目录刷新，发送仍来自原生输入框；Host 自动选择可用的自部署 q3 模型并改写 `turn/start`，同时阻止非 q3 普通入口。

`continuation.ts` 提供按需读取的最近中断原生会话列表、会话链接和一键继续。请求期间禁用对应按钮，失败保留错误与重试入口；隐私模式卸载此区域。列表不参与状态轮询，Host 再次校验回合身份和运行状态。

`planner-input.ts` 在规划提问时自动展开确认卡片，支持选项、自由文本、提交重试和取消。按会话及请求保留输入 DOM，轮询不重置回答；切换 Host、会话或关闭路由时清除旧卡片。
