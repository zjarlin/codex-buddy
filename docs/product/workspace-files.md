# 工作区文件浏览与预览

## 当前行为

Codexhost 在 Desktop 左侧第二栏提供“文件浏览器”。文件树属于 Renderer 扩展，不移动也不复用 Codex Desktop 私有 React 文件面板；文件读取通过 Host RPC 完成。

- `codexhost/workspace/files/list` 列出工作区中指定目录的一层内容。
- `codexhost/workspace/files/read` 读取单个文件，供对话区域上的只读预览使用。
- 目录按需加载。点击目录才读取下一层，避免打开项目时扫描整个仓库。
- 点击文件后，预览覆盖默认主对话表面；关闭预览或按 `Escape` 后恢复原界面。扩展不修改对话 DOM。
- 文件树过滤工作区根目录的 `.git`。子模块目录仍按普通目录展示。

## 安全与限制

Host 将请求路径解释为工作区内的 POSIX 风格相对路径，并拒绝绝对路径、空路径段以及 `..` 越级。访问前会解析真实路径，符号链接只有在最终目标仍位于工作区内时才允许。

单次目录列表最多返回 5000 项。单次文件读取最多返回 1 MiB 内容；超出的文件会标记 `truncated`。包含 NUL 字节的内容会标记为 `binary`，不向 Renderer 返回二进制正文。这些上限用于避免大型工作区或异常文件阻塞 Desktop。

## 边界

文件浏览和文件预览没有编辑、保存、重命名或删除能力。Git 变更、暂存和提交仍由 Git 侧栏负责；文件面板只展示工作区实际内容。官方右侧文件面板保持不变，终端按钮仍转发官方终端面板。

## 验证

- Host 单测覆盖目录排序、嵌套读取、路径逃逸、符号链接逃逸、二进制识别和截断。
- Renderer Playwright 覆盖左侧文件树、目录懒加载、文件点击预览、关闭预览，以及文件按钮不再触发官方右侧面板。
