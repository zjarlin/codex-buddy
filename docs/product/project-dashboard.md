# 项目态势大屏

`codexhost` 默认在主工作区打开“项目态势”，应用标题栏同时保留甘特图入口。大屏覆盖官方主工作区，但不替换官方聊天、侧栏或原生导航；点击“切换到聊天”、点击结果回合或点击侧栏会话后返回原会话。大屏面向只看结果的盯盘场景，展示项目、会话和最近回合，不展开推理、工具调用或完整聊天记录。

## 数据与展示

- 按 Host 与原工作区路径聚合项目；同一路径下的会话放在一张项目泳道中。
- 每个会话只读取最近 6 个回合，并额外请求 `full` Items：最终总结来自最后一个 `agentMessage`，文件变更来自 `fileChange`，没有显式增删行时从 unified diff 计算。
- 项目卡片汇总运行中的会话、每个会话最新的完成结果、涉及文件数和增删行；失败和中断回合保留状态，但不计入“最新完成结果”。
- 回合卡片显示请求摘要、最终总结、状态、耗时和文件变更统计。点击卡片回到对应原生会话。
- 数据只来自各 Host 的 `thread/list` 与 `thread/turns/list` 只读投影，不读取或修改 Harness 私有状态，也不改变官方 Thread 的所有权。

## 生命周期

默认视图在每次应用启动时进入盯盘；用户本次运行中显式切换到聊天后不再自动弹回。标题栏入口位于官方原生操作组，按 Host 路由稳定重定位。大屏跟随官方主工作区尺寸；窗口隐藏时不轮询，恢复可见或点击“刷新”时立即重读。打开期间每 30 秒刷新一次，卸载扩展时同时释放轮询、观察器和大屏节点。

## 验证边界

`packages/renderer-extension/test/renderer-project-dashboard-state.test.ts` 验证项目聚合、回合摘要、文件去重与失败隔离。`tests/e2e/renderer-project-dashboard.spec.ts` 覆盖默认进入、标题栏入口、主工作区覆盖、结果展示、刷新、切换到聊天、打开原会话和卸载清理；该用例需要可启动的 Chromium。
