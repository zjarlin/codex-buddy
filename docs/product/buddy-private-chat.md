# q3 模型选择

`q3-4b`、`q3-14b` 是当前 Provider 的普通模型 ID，使用原生输入框、会话历史和工具能力。路由设置不再提供隐私模式开关，模型选择不建立额外隔离或发送限制。

## 使用

在原生模型菜单中选择所需 q3 ID；也可在路由设置中将它设为固定执行模型。工具、审批、外部 Harness、会话续接、压缩、目录刷新、可用性探测和播报继续遵循各自原有能力和设置，不受模型名称限制。`【隐私】`、`/private` 等文本不再触发 Host 发送拦截。

## 旧配置兼容

读取或写入旧的 `privateMode: true` 设置时，将它转换为普通固定执行模型配置：保留 `q3-4b` 偏好，否则选择 `q3-14b`；开启路由，执行角色为通用，关闭 System One 判断和工具／Git 旁路，使普通请求直接选择该模型。回传及再次保存的 `privateMode` 均为 `false`。用户可随后选择任意其他模型或修改普通路由设置。

固定模型不可用时使用普通路由错误，不把模型 ID 当作执行位置或隐私资格。请求仍经过当前 Provider 与原生 App Server，模型的工具支持由实际能力决定。

旧的 `codexhost/buddy/private` 内存纯文本接口保留为历史兼容代码，主界面不挂载该入口，也不再通过已移除的开关启用它。
