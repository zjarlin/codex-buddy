# 项目清单同步

CodexBuddy 的「设置 → 项目」维护独立项目清单，不修改 Codex Desktop 私有数据库或原生项目侧边栏。它不是 Harness Adapter 插件。两种传输方式共享同一份本机清单，可单独使用，也可同时使用。

## 设备配对

默认使用 `wss://aio.addzero.site/codexhost-relay/`，也可用 `CODEXHOST_PROJECT_SYNC_RELAY_URL` 覆盖。两台客户端主动连接同一个中继，不需要公网 IP、入站端口、用户账号或 frpc。设备 A 点击「生成配对码」，设备 B 输入八位码，设备 A 在「待确认的配对」中核对名称与指纹并点击「同意」。邀请码五分钟有效；拒绝不会建立信任。配对完成后选择设备「同步」，交换项目名称和 Git origin URL。

中继只转发短码、设备公钥、审批信令与加密消息，不持久保存清单。设备身份使用本机 Ed25519 密钥，项目消息由 X25519 派生密钥后用 AES-256-GCM 加密。客户端仅允许 WSS；`ws://127.0.0.1` 和 `ws://localhost` 仅供本机测试。重启后配对关系保留，客户端在设置页可用时重新注册；撤销只清除本机信任，另一台设备仍需自行撤销。中继是传输服务，不是严格的 P2P 直连。

自托管：在仓库根目录执行 `npm run build:typescript`，然后运行 `CODEXHOST_RELAY_HOST=127.0.0.1 CODEXHOST_RELAY_PORT=8642 node scripts/project-sync-relay.mjs`。生产环境需将该端口置于 HTTPS 反向代理之后，公开 WSS 地址，并配置访问限流及运行监控。不要把生产 frps 的共享 token 交给客户端。

## Git 清单

在「私有 Git 清单仓库」中配置一个已有初始提交的仓库 HTTPS/SSH 地址，使用本机 Git 凭据。点击「发布清单」会先读取远端清单、合并本机新增项目，提交并普通推送 `codexbuddy-projects.json`；另一台可点击「拉取清单」。并发推送冲突、认证失败或受保护分支会报错，不强推。Git 仓库地址不得带凭据。此路径不依赖中继和配对。

两种方式都只同步项目名与 Git origin URL，不上传源码、本机路径、未提交文件、会话或凭据。对本机缺失的项目可绑定已有的同 origin 仓库或克隆到空目录，然后通过 Codex Desktop 自身入口打开项目。删除、重命名不会自动传播。

本机状态与设备密钥保存在 `CODEXHOST_DATA_DIR/project-sync/`，默认 `~/.codexhost/project-sync/`。旧本机清单的项目和目录绑定继续可读；此前原型里的隧道地址记录不再作为新配对凭据使用。

## 远程聊天切回本地

远程聊天标题栏的「切回本地」默认使用会话所属远程项目的原绝对路径，例如 `/Users/zjarlin/aio/workspace/公司的项目/okm-platform`。本地路径以只读形式显示，点击「选择本地目录…」浏览本机目录，确认「选择此目录」才会覆盖默认值；取消保留原路径。「使用远程同一路径」恢复默认。显式选择按远程 Host 和项目目录记忆；旧版输入框保存的路径不自动覆盖默认值。默认目录不存在时，选择器从最近存在的父目录开始浏览，也可切到本机主目录。

Git 来源从会话当前所属项目的 `origin` 自动读取并展示，按 Host 和项目路径缓存最近 64 个项目。原生 SSH 连接没有扩展接口时，复用本机 Host 的 SSH Git 通道。读取失败时使用项目缓存，首次读取可使用同目录的会话 Git 元数据；新读取为空会清除旧 origin，不从其他主机或其他目录猜测来源。远程宕机时使用已保存的上下文与 Git 来源，界面标明缓存状态；从未缓存且无法读取的来源不能凭空恢复。

目录不存在时，本机 Host 创建父目录并使用本机 Git 凭据克隆到该完整路径；缺少 Git 来源时提示恢复远程连接。已有目录必须是 Git 仓库根目录；已获取 Git 来源时，还需与现有 origin 对应。已有工作区不会被拉取、清理或覆盖，失败克隆只清理本次创建的目标目录。

点击「准备目录并续接」后，以本机 Codex 默认配置新建聊天，把历史消息和工具结果作为首条上下文发送，并加入本地项目。首条消息仅要求确认上下文、等待用户下一条指令。原聊天保留；这不是 Fork 或原生 Session 迁移，不复制 Agent 内部状态、附件、远端未提交文件或远端权限设置，也不会停止远程任务。新的聊天使用本机文件现状，Git 克隆使用仓库默认分支。

窗口可见且正在查看远程聊天时，每 30 秒只读刷新一次上下文；切入远程聊天和打开入口时也会读取。远端不可用时使用最近成功缓存，界面显示缓存时间；无缓存则阻止续接。最多缓存最近 8 个聊天，每个最多保留最近 120,000 个 UTF-16 字符，超限会明确显示历史截断提示；内部推理不进入上下文。快照、项目 Git 来源与目录映射保存在当前 Desktop 浏览器配置的本地存储中，不经过项目清单中继或 Git 清单。清理 Desktop 浏览器数据会清除这些缓存。

本地聊天创建后若发送、项目登记或导航失败，入口保留新聊天 ID 和「打开本地聊天」按钮，当前对话框不会重复创建或重发；用户应核对该聊天的实际状态。切换需要本机 Host 提供 `codexhost/local-workspace/prepare`，目录选择需要本机 Host 的 `codexhost/local-workspace/directories`。远端聊天使用原生 `thread/read`，项目来源使用 `codexhost/git/origin` 或本机 SSH Git 通道。
