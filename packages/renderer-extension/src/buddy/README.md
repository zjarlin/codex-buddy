# Buddy 控件

`installBuddyControl` 从现有 renderer 绑定获取当前 Codex 任务、输入框锚点和 Host 客户端，在输入框前放置 Auto Router。仅通过共享浏览器安全契约调用 Host；不读取 Node、文件或供应商凭据。

提供双语、键盘可操作的开关、角色和两档模型设置。面板按“路由”“中断会话”“任务详情”分 tab，路由 tab 使用双栏紧凑布局，帮助说明放在控件提示中；关闭 Auto Router 或开启隐私开关时，普通路由配置保留可见但禁用。模型刷新属于独立收藏入口；最近中断会话同时显示在中断 tab 和侧边栏会话状态图标，面板条目可手动恢复。任务详情展示规则评分、阶段、任务包、原生接受的模型和旁路退出码。状态每 1.2 秒读取一次，中断列表最多每 15 秒读取一次；只有手动刷新或真实路由访问模型目录。`dispose()` 释放轮询和 DOM。

“JEV 判断”开关控制 System One 回合判断，开关下方提供密码类型 API Key 输入、保存与清除，仅显示“已配置/未配置”；详情行显示 JEV 模型和逐题状态。推送模型旁路以蓝色“旁路 · 垃”突出显示，折叠时仍展示实际模型、跳过夯规划和旁路回合成功率。详情显示样本数、统计口径及附带技能；完成、失败和取消后保留旁路标识，不与零模型命令旁路混淆。

模型收藏由 `renderer-model-shortcuts.ts` 管理，复用 `renderer-model-favorites.ts` 的 Harness 隔离存储。收藏即 Pin，目录缺失的 ID 仍显示和可移除；仅声明 `supportsCustomModel` 的原生 Codex 绑定允许手填或选择目录外 ID，外部 Harness 的缺失项禁用。手填输入保留精确 ID，“使用此 ID”选择，“Pin 此 ID”仅持久化。原生绑定读取已发布的菜单属性并调用同一选择回调，不修改目录或发送请求；未知 ID 不携带旧模型的思考强度。手填和 chip 都通过 `renderer-fixed-model-selection.ts` 先关闭 Auto Router 接管和隐私改写，成功后才切换模型；固定模型保留规划偏好，面板可再次开启 Auto Router。

模型刷新统一经过 `renderer-native-model-refresh.ts`：供应商同步完成后 refetch 原生模型查询，等待 committed 菜单的 ID 集合与 Host 热目录一致，再显示计数。等待有两秒上限，每个异步阶段校验当前 Composer、Host、Harness 和请求版本；超时提示刷新重试，不再要求重启。Host 的 `buddy/live-model-catalog.ts` 负责将已验证同步目录投影到 `model/list`，Renderer 不改写原生 QueryClient 数据或 React 状态。

折叠摘要和“本次任务模型”展示规划模型、执行模型、任务中切换过的模型及已报告的子代理模型，去重并允许换行，不把整个候选目录列作参与模型。兼容旧 Host 未提供模型记录时的当前规划/执行字段。显式指定执行模型时，提示单模型执行、禁止子代理和自动换模；选择“动态选择”恢复自动策略。

通过 `node tools/buddy/preview.mjs` 验证真实组件的模拟场景；执行 `npm run build:renderer` 后由主 renderer 扩展安装。夹具不能替代完整桌面绑定验收。参见 [功能说明](../../../../docs/product/buddy-auto-router.md)。

隐私模式不挂载独立输入区，也不隐藏原生 composer。启用隐私开关后，隐藏手动选模和普通目录刷新，发送仍来自原生输入框；Host 自动选择可用的自部署 q3 模型并改写 `turn/start`，同时阻止非 q3 普通入口。

`continuation.ts` 独立挂载侧边栏状态图标恢复入口，按 Host 分页读取未归档会话，每 15 秒最多检查一次，聚焦时刷新。仅对确认归属 Codex 且最新回合中断的行覆盖原生状态槽，保留 React 节点，支持重绘及卸载还原；运行中、隐私模式下移除按钮，关闭路由仍允许手动恢复。展示和点击校验使用相同的 Host 前缀归一化会话 ID。请求期间防重复点击，失败显示可重试错误；Host 再次校验回合身份和运行状态。

`interrupted-panel.ts` 管理中断页签的列表、手动刷新、单条恢复和“全部继续”。批量只逐条提交点击时的当前 Host 列表，成功项移除，失败项保留并显示原因；切换 Host、卸载或开启隐私时停止剩余提交。列表读取失败保留已知记录并按轮询间隔重试，部分历史不可读时显示数量，成功恢复的回合不会被滞后的列表响应重新加入。固定模型模式保留完整入口，隐私模式显示不可续接原因。

`planner-input.ts` 在规划提问时自动展开确认卡片，支持选项、自由文本、提交重试和取消。按会话及请求保留输入 DOM，轮询不重置回答；切换 Host、会话或关闭路由时清除旧卡片。
