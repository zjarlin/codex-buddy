# 工作区文件浏览与编辑

## 当前行为

Codexhost 在 Desktop 左侧第二栏提供“文件浏览器”。文件树属于 Renderer 扩展，不移动也不复用 Codex Desktop 私有 React 文件面板；文件读取和保存通过 Host RPC 完成。

- `codexhost/workspace/files/list` 列出工作区中指定目录的一层内容。
- `codexhost/workspace/files/read` 读取单个文件，同时返回基于内容的 SHA-256 `revision`。
- `codexhost/workspace/files/write` 写入已有文本文件，并要求请求携带读取时的 `expectedRevision`。
- 目录按需加载。点击目录才读取下一层，避免打开项目时扫描整个仓库。
- 点击文件后在默认主对话表面打开 CodeMirror 编辑器。支持编辑、`Cmd/Ctrl+S` 保存、未保存标记和保存状态提示。
- 关闭编辑器、切换侧栏视图或切换文件前，如果有未保存修改会要求确认。扩展不修改对话 DOM。
- 文件树过滤工作区根目录的 `.git`。子模块目录仍按普通目录展示。

## 安全与限制

Host 将请求路径解释为工作区内的 POSIX 风格相对路径，并拒绝绝对路径、空路径段以及 `..` 越级。访问前会解析真实路径，符号链接只有在最终目标仍位于工作区内时才允许。

单次目录列表最多返回 5000 项。单次文件读取和写入最多 1 MiB；超出的文件会标记 `truncated` 并保持只读。包含 NUL 字节的内容会标记为 `binary`，不向 Renderer 返回正文，也不能写入。这些上限用于避免大型工作区或异常文件阻塞 Desktop。

保存前 Host 会重新读取文件并比较 `expectedRevision`。如果文件已被其他程序修改，写入会被拒绝，Renderer 保留当前草稿并显示冲突原因，避免静默覆盖。写入通过同目录临时文件和原子替换完成，并保留原文件权限。

## 边界

文件浏览器不提供新建、重命名或删除能力；当前保存范围是已有普通文本文件。二进制文件、符号链接和超过 1 MiB 的文件保持只读。Git 变更、暂存和提交仍由 Git 侧栏负责。官方右侧文件面板保持不变，终端按钮仍转发官方终端面板。

## 验证

- Host 单测覆盖目录排序、嵌套读取、路径逃逸、符号链接逃逸、二进制识别、截断、revision 写入和冲突拒绝。
- Renderer Playwright 覆盖左侧文件树、目录懒加载、文件编辑、快捷键保存、脏状态、冲突提示、关闭编辑器，以及文件按钮不再触发官方右侧面板。
